# 🏠 הבית שלי — העלאה ל-GitHub Pages

אפליקציית ניהול קניות ותחזוקת בית. **כל הנתונים נשמרים במכשיר בלבד.**

---

## חלק א' — האם המידע שלי באמת פרטי?

כן, וחשוב להבין למה — יש כאן שני דברים **נפרדים** לחלוטין:

| מה | איפה זה יושב | מי יכול לראות |
|---|---|---|
| **הקוד** (`index.html`) | ב-GitHub | תלוי אם המאגר ציבורי או פרטי |
| **הנתונים שלך** (הרשימות) | `localStorage` בדפדפן שלך | **אתה בלבד** |

האפליקציה לא מבצעת **שום** קריאת רשת — לא לשרת, לא ל-API, לא לגופנים חיצוניים (נבדק: אפס כתובות חיצוניות בקוד). GitHub מארח קובץ HTML סטטי ותו לא. גם אם המאגר ציבורי לגמרי, אף אחד לא רואה שאתה צריך לקנות חלב — הרשימות פשוט לא נמצאות שם.

> **המשמעות המעשית:** מאגר ציבורי זה בסדר גמור כאן. אתה חושף רשימת קניות גנרית שממילא שלחתי לך, לא מידע אישי.

### אם בכל זאת תרצה מאגר פרטי
GitHub Pages זמין ממאגר פרטי רק עם **GitHub Pro** ומעלה (בחשבון אישי). חשוב לדעת: **גם אז האתר עצמו נשאר ציבורי** — רק הקוד מוסתר. אתר Pages *פרטי* באמת דורש ארגון ב-GitHub Enterprise Cloud עם Pages access control.

מסקנה: אם המטרה היא פרטיות מידע — המאגר הציבורי מספיק. אם המטרה היא להסתיר את הקוד — צריך Pro.

## חלק ב' — העלאה (5 דקות, בלי Git)

1. היכנס ל-[github.com](https://github.com) → **New repository**.
2. שם: `bait` (או כל שם). בחר **Public**. סמן ✅ *Add a README*. → **Create**.
3. במאגר: **Add file → Upload files**.
4. גרור את **כל 5 הקבצים**: `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png` → **Commit changes**.
5. **Settings → Pages** → תחת *Build and deployment*:
   - Source: **Deploy from a branch**
   - Branch: **main** / תיקייה: **/ (root)** → **Save**
6. המתן 1–2 דקות. הכתובת תופיע למעלה:
   `https://<שם-המשתמש>.github.io/bait/`

### עדכון גרסה בעתיד
Upload files → גרור את הקובץ החדש → Commit. הוא דורס את הישן. **הנתונים שלך לא נמחקים** — הם לא חלק מהקוד.

## חלק ג' — התקנה כאפליקציה

**אייפון (Safari):** פתח את הכתובת → כפתור שיתוף ⬆️ → **הוסף למסך הבית**.
**אנדרואיד (Chrome):** פתח את הכתובת → תפריט ⋮ → **התקן אפליקציה**.
**מחשב (Chrome/Edge):** אייקון ההתקנה ⊕ בשורת הכתובת.

אחרי ההתקנה זה נפתח כאפליקציה עצמאית, **עובד גם בלי אינטרנט** (Service Worker), בלי שורת כתובת.

## חלק ד' — שכבות הגנה נוספות

- **🔒 קוד נעילה** (כפתור בתחתית): מגן מפני מישהו שמרים לך את הטלפון. הקוד נשמר כ-SHA-256, לא כטקסט גלוי. זו הגנה מפני הצצה — לא הצפנה של הנתונים.
- **שם מאגר לא צפוי**: אם מפריע לך שהכתובת ניחושה, קרא למאגר משהו כמו `h7k2n9` במקום `bait`.
- **`noindex`**: כבר מוטמע בקוד — מנועי חיפוש לא יאנדקסו את הדף.
